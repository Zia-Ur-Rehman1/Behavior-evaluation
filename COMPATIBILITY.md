## Rails 5 — FAILED

**Bundler cannot resolve dependencies.** Root cause:

```
Because turbo-rails >= 0.9.1, < 2.0.13 depends on railties >= 6.0.0
  and every version of extendable-rails depends on turbo-rails >= 1.0,
  every version of extendable-rails requires railties >= 6.0.0
```

The gem's runtime dependency on `turbo-rails >= 1.0` transitively requires
`railties >= 6.0.0`. No version of turbo-rails that supports the `--turbo`
generator flag exists for Rails 5.x. This is a **hard incompatibility in the
dependency graph** — not a code-level issue.

**Action taken:** gemspec updated — minimum `railties` bumped from `>= 5.2` to
`>= 6.0` to accurately reflect the real supported range.

## Rails 6.1 — PASSED

All 53 smoke-test checks and 216 RSpec examples pass.
Requires pinning `concurrent-ruby 1.3.4` and restoring removed stdlib gems
(`logger`, `mutex_m`, `bigdecimal`, `drb`, `base64`) when running under
Ruby 3.1+. See `gemfiles/rails_6.gemfile`.

## Rails 7.1 — PASSED

All 53 smoke-test checks and 216 RSpec examples pass. No special pins needed.

## Rails 8.1 — PASSED

All 53 smoke-test checks and 216 RSpec examples pass.

**Environmental note:** Rails 8.1.2's ActionView triggers a parser bug on
Ruby 3.3.0 (anonymous parameters inside blocks — fixed in Ruby 3.3.1).
The gem itself does not use ActionView; the smoke test was adjusted to load
only `railties` + `active_support`. In a real Rails 8 app running Ruby 3.3.1+
this is a non-issue.

## What the smoke test covers

1. Module-level API (`configure`, `reset_configuration!`, `VERSION`)
2. Configuration (`add_llm_provider`, defaults, provider list)
3. `Severity` — coercion, ranking, thresholds, labels, descriptions
4. `ErrorEvent` — wrapping, backtrace, fingerprint, `to_h`, `summary`
5. `Notifiers::Base` — threshold filtering, exception swallowing
6. `Notifiers::Logger` — severity → log-level mapping
7. `Notifiers::Slack` — payload construction, per-severity colours
8. `Notifiers::Email` — subject/body generation
9. `Reporter` — register, dispatch, `capture`, severity helpers
10. Module delegates — `ExtendableRails.report_error`, `.capture`, `.error_reporter`
11. `Mcp::Llm::Provider` — circuit breaker (open/close/cooldown)
12. `Mcp::Llm::ProviderManager` — failover + auto error reporting
13. `Mcp::Authentication` — `:none`, `:api_key` strategies
14. `Mcp::ContextWindow` — usage extraction, status transitions
15. `Railtie` + generator registration

## Reproducing locally

```bash
# All at once
./bin/test_all_rails

# Single version
BUNDLE_GEMFILE=gemfiles/rails_7.gemfile bundle install
BUNDLE_GEMFILE=gemfiles/rails_7.gemfile bundle exec ruby test_apps/smoke_test.rb
BUNDLE_GEMFILE=gemfiles/rails_7.gemfile bundle exec rspec spec/extendable_rails/
```
